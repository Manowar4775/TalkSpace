Privacy & safety

How privacy currently works in the app.

This page describes protections and controls that are currently implemented. It does not add privacy settings that the app cannot enforce.

Private communication

  • Private chats and voice or video calls are available only between accepted friends.
  • If either person has blocked the other, messaging and calls are unavailable.
  • If TalkSpace cannot verify friendship or block status, it denies access instead of assuming it is allowed.

When a friend is offline

A friend's private chat history and last-message preview are hidden while they are offline. The message composer is unavailable, and calls cannot be started. Live updates use the same access checks; an older in-progress request must not reveal chat content after the state changes.

Information used to provide TalkSpace

TalkSpace uses Supabase Authentication for account access. The app also stores profile details (username, display name, and avatar URL), friend-request and block records, online presence, messages and their delivery or seen state, and call-signalling data needed for communication. These features use the configured Supabase services for authentication, database storage, and realtime updates.

Controls available in the app

  • Block or unblock a person from the TalkSpace app. A block prevents private communication in either direction.
  • Use the chat's message controls to delete a message for yourself, delete it for everyone where available, or clear your chat view.
  • Manage your supported profile display name in Settings.

Preferences not currently available

TalkSpace does not currently provide user-configurable controls for online visibility, profile-field visibility, or a profile bio. Those options are not presented as active settings because the current application does not support saving or enforcing them.
